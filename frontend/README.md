# Employee Demo: Next.js front end

Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · TanStack Query · React Hook Form + Zod

```powershell
npm install
npm run dev        # http://localhost:3000  (start the .NET API first: ../backend)
npm run lint
npm run typecheck
npm run build      # production build (.next/standalone)
```

Environment variables: see [.env.example](.env.example).
